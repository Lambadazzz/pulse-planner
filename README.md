# Пульс · GitHub и Android

Сайт: https://lambadazzz.github.io/pulse-planner/. Android 0.4.1 содержит тот же React-интерфейс внутри APK, локальное хранилище, очередь изменений, чтение двух филиалов OMNI и напоминания. На компьютере остаётся GitHub Pages. Данные хранятся зашифрованными в отдельном приватном репозитории, Sites в новой версии не используется.

## Обновление 0.4.1

Над расписанием кнопка «Обновить»: на Android читает оба филиала OMNI и завершает обмен с GitHub; на компьютере загружает данные из GitHub. Стрелки вращаются до ответа, повторное нажатие отключено. Только полный успех показывает зелёное «Готово» на 3 секунды. Ошибки OMNI/GitHub и конфликты показываются отдельно, не выдаются за успех. При ошибке OMNI задачи всё равно синхронизируются с GitHub, если он доступен.

## Интерфейс 0.4.0

Рабочий день преподавателя, увеличенные шрифты, компактная сиреневая карточка с декоративным акцентом, кнопка добавления в верхней панели. Тема переключается автоматически в 20:00 и 06:00 по Москве, включая уже открытый экран. Светлая и тёмная палитры согласованы с цветом системных значков Android. Тема не требует сети. tests/theme.test.mjs проверяет границы времени и возврат на экран.

## Подключение

Установить APK поверх прежней версии, сохранив данные приложения. Существующее GitHub-подключение, очередь выполнения и кэш мигрируют автоматически. Новая установка просит GitHub login, приватный репозиторий, fine-grained PAT только к нему с Contents: Read and write и отдельную фразу шифрования от 12 символов. На компьютере используется тот же репозиторий и фраза. Фразу нельзя восстановить при потере.

В приложении: «Настройки» → «Открыть настройки Android и OMNI». Здесь вход OMNI, его зашифрованные локальные реквизиты, чтение Академии/Колледжа, разрешения уведомлений и точных будильников, немедленный тест уведомления, будильник через минуту и копируемая диагностика.

## Без сети и конфликты

В Android можно видеть расписание, создавать, редактировать, удалять и выполнять задачи без интернета. Правки подтверждаются только после записи на диск под Android Keystore. Экран показывает число ожидающих отправки изменений. GitHub-синхронизация работает отдельно и не блокирует локальную правку сетевым запросом.

Слияние использует SHA файла и revision задачи. Изменения разных задач объединяются. При конфликте локальная версия остаётся на телефоне; «Настройки» → «Сравнить конфликтующие правки» позволяет явно выбрать телефон или GitHub. Выбор GitHub отменяет локальные правки выбранной задачи. Изменения, появившиеся во время отправки, не удаляются при подтверждении более раннего запроса. Свежий снимок OMNI сохраняется локально и остаётся в очереди при сетевой ошибке.

На сайте в браузере создание и редактирование по-прежнему требуют связи. Android-очередь работает только в APK.

## Напоминания и ограничения

Уже сохранённая на телефоне задача планирует локальное напоминание, включая созданную офлайн. Нужно разрешить уведомления приложения, канал «Напоминания о своих делах» и точные будильники. Без точных будильников время приблизительное. Фоновую работу и поведение прошивки необходимо проверить на конкретном устройстве; после принудительной остановки приложение нужно открыть снова.

При открытой оболочке GitHub проверяется примерно каждые 15 секунд и при возврате. В фоне JobScheduler проверяет дела примерно раз в 15 минут, OMNI — раз в час. Android может откладывать задания. Мгновенная доставка новой задачи с компьютера на закрытый телефон не гарантируется.

Доставка уведомлений и кнопка «Выполнено» подтверждены пользователем в APK 0.3.0. Android может скрывать действие в свёрнутом уведомлении: нужно раскрыть его. Настройка «За 15 минут» относится к времени задачи; для напоминания в момент начала выбирайте «В начале». Уже прошедшие моменты напоминания не планируются. Диагностика регистрирует приём будильника, вызов Receiver, результат NotificationManager и ошибки.

## Безопасность

GitHub-файл: AES-256-GCM, PBKDF2-HMAC-SHA256 (600000 итераций), случайные соль и IV. PAT передаётся только GitHub API, фраза туда не отправляется. В Android настройки и единый документ очереди защищены Android Keystore; браузерное запомненное подключение шифруется фразой.

WebView интерфейса обслуживает только встроенные assets на HTTPS appassets.androidplatform.net; загрузка сети, file/content URLs и сторонняя навигация запрещены. Нативный мост не раскрывает сохранённые PAT/фразу и не добавляется в OMNI WebView. Личные данные, ключи подписи и локальное состояние не включать в исходники/публичный репозиторий.

## Сборка и проверки

Node >=22.13, `npm install`. Сайт: `npx vite build --config github-app/vite.config.ts`. Android на Windows с JDK: `scripts/setup-android.ps1`, затем `scripts/build-android.ps1`. Скрипт собирает интерфейс и включает HTML/JS/CSS/иконки в APK, не включает APK внутрь себя. Результат: outputs/pulse-omni-test.apk и github-app/public/pulse-android.apk. Тестовый ключ подписи находится только в ignored .sites-runtime; для обновления своего APK сохраняйте его, не публикуйте.

`scripts/test-android-core.ps1` проверяет 26 сценариев очереди/слияния и 9 сценариев времени напоминаний на JVM. org.json загружается из Maven Central только для тестов, SHA256 проверяется; в APK используется встроенный org.json Android. `tests/github.test.mjs` проверяет веб-шифрование и конфликты двух клиентов с имитацией API. `tests/crypto-interop.mjs` проверяет совместимость Java/WebCrypto. UI-стенд `node scripts/preview-native.mjs` использует тестовый мост и вымышленные данные на loopback; он не заменяет запуск APK на телефоне.

Перед публикацией 0.4.0 проверены сборка, подпись v2/v3, TypeScript, JVM-очередь/время, веб-синхронизация и локальный UI-стенд. APK 0.3.0 и уведомления подтверждены пользователем. Обновление интерфейса 0.4.0 проверено на визуальном стенде; системные значки Android требуют просмотра на устройстве. Старый Sites не удалён до завершения переноса и отдельного решения пользователя.
