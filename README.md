# Пульс · GitHub

Диагностическое обновление Android 0.2.2: кнопки немедленного тестового уведомления, тестового будильника через минуту и «Диагностика напоминаний». Журнал остаётся на телефоне, содержит статусы разрешений и этапы выполнения, не содержит токенов/паролей. Первая проверка уведомления задачи 0.2.1 на телефоне не прошла; причина пока не подтверждена. Сборка и подпись новой версии проверены; 9 проверок расчёта времени в Java прошли. Проверить на телефоне отдельно немедленное уведомление и будильник.

Статический React/TypeScript интерфейс на GitHub Pages. Приватное хранилище — файл `pulse-vault.json` в отдельном приватном репозитории. Сервер Sites в этой версии не используется.

## Подключение

1. Создать fine-grained GitHub PAT только для `pulse-planner-data`, Contents: Read and write. Остальные разрешения не нужны, кроме обязательного Metadata: Read.
2. На сайте указать владельца, репозиторий, PAT и отдельную фразу шифрования длиной минимум 12 символов. Одинаковая фраза нужна на всех устройствах; восстановить её нельзя.
3. В Android-помощнике настроить то же хранилище и фразу, разрешить уведомления и точные будильники. OMNI подключается отдельно на телефоне.

PAT передаётся только GitHub API. Фраза не отправляется на сервер. Сохранённое браузерное подключение зашифровано фразой; Android хранит настройки через Android Keystore. Не включать токены, фразы и личные данные в исходники или коммиты.

## Поведение и ограничения

- AES-256-GCM, PBKDF2-HMAC-SHA256, 600000 итераций, случайные соль и IV. Проверяется подлинность шифротекста.
- Изменения браузера загружаются сразу, чтение при открытом интерфейсе — примерно каждые 15 секунд. Обновления используют SHA файла и проверку версии задачи.
- Android проверяет задачи фоновым JobScheduler примерно раз в 15 минут, расписание OMNI — раз в час. Android может откладывать фоновую работу. При открытии выполняется дополнительная синхронизация.
- Уже полученные задачи напоминают локально без сети. Кнопка «Выполнено» сохраняет отметку локально и отправляет её при возможности. Мгновенная доставка новых задач с компьютера на закрытый телефон не гарантируется.
- Без разрешения точных будильников время уведомления приблизительное. Реальное поведение зависит от настроек энергосбережения телефона.
- Веб-разблокировка пока требует сети. Публичная оболочка кэшируется, личные данные в service worker не кэшируются.
- Старую версию Sites сохранять до подтверждённого переноса. Импорт её JSON доступен в настройках новой версии.

## Сборка и проверки

Из корня исходников: `npm install`, затем `npx vite build --config github-app/vite.config.ts`. Файлы из `github-app/dist` публикуются в корне Pages. Android: `scripts/setup-android.ps1`, затем `scripts/build-android.ps1`; требуется JDK и Windows Android SDK.

Проверки: `tests/github.test.mjs` проверяет шифрование и конфликты двух клиентов с имитацией GitHub API. `tests/crypto-interop.mjs` проверяет совместимость Java и WebCrypto. Перед ними собрать `tests/github-entry.ts` и `github-app/src/store.ts` через esbuild в `.sites-runtime/github-core.mjs` и `.sites-runtime/github-store.mjs`.

APK 0.2-github собран и проверена подпись. Уведомления и реальная GitHub-синхронизация требуют отдельной проверки на устройстве с пользовательским подключением. Предыдущая версия чтения OMNI обоих филиалов проверена пользователем.
